8. 权限门状态机与 5 种用户选择

源码：permissions/gate.py。单 FIFO 队列，TIMEOUT=300s。run 开始时 reset_run_flags 清掉 deny_rest / allow_rest。

stateDiagram-v2 [*] --> Idle Idle --> Pending: ASK 到来 入队并 emit PERMISSION_REQUEST Idle --> DenyRest: deny_rest 生效 Idle --> AllowRest: allow_rest 生效 DenyRest --> DenyRest: 本 run 后续 ASK 直接 DENY AllowRest --> AllowRest: 本 run 后续 ASK 直接 ALLOW Pending --> Resolved: 用户选择 / abort Pending --> Expired: 300s 超时 Resolved --> Idle: 出队并清理 Expired --> Idle: emit PERMISSION_EXPIRED 返回已拒绝 绝不补执行 Idle --> [*]
用户选择动作副作用
allow_once本次放行不记忆
allow_dir本次放行写入目录级规则，TTL 30 天
allow_rest本次放行本 run 后续 ASK 全部自动放行
deny本次拒绝无
deny_rest本次拒绝本 run 后续 ASK 全部自动拒绝
（无响应）300s 后拒绝emit PERMISSION_EXPIRED
（用户 abort）全部待决释放为 DENY避免卡在 300s 超时后

13. 事件字典：19 种事件与落盘/回放语义

事件落 transcript映射回 LLM messages触发时机
message是是（user / assistant 文本）用户输入、助手回复、终止提示
function_call是是（assistant tool_calls）模型产出每个工具调用
function_call_result是是（tool_result / role=tool）每个工具返回（含拒绝文案）
reasoning是否模型返回 reasoning_content
file-history-snapshot是否写工具前后各一条
permission_request / resolved / expired是否ASK 生命周期
turn_budget_warning是否第 32 轮
skill_loaded是否自动匹配加载或 use_skill
run_started / run_finished / run_aborted是否run 边界
artifact_presented是否present_files 成功且有卡片
context_usage是否每轮估算 + 官方用量校准各一次
context_limit_exceeded是否出口②
final_prompt是否每轮 sanitize 后的真实请求快照
error是否预留错误通道
assistant_delta / reasoning_delta否（sequence=0）否流式 chunk，仅 SSE
SSE 端点（api/routers/events.py）双段式：先 read_since(last_id) 回放历史，再 subscribe() 接 live 流。assistant_delta 是 bus-only（sequence=0，不持久化），靠 ev.sequence > last_id 过滤避免重复。底层 EventBus 是单进程 asyncio.Queue（events.py L15-L42），FastAPI 强制 workers=1。

17. 已知架构缺口

来自项目 memory 的记录，这些是当前实现中尚未闭合的设计缺口：

缺口现状影响
Memory 写路径完全缺失UserMemory.add() / WorkspaceMemory.add() 从未被调用三层优先级架构只有读路径生效，memory 表始终为空
recall() 未集成render_segment() 加载全部 memory items无相关性过滤，prompt 注入无关记忆
Compact 摘要不持久化会话压缩后摘要只留在 controller 内存重启后情景记忆丢失，跨会话无法继承
检索评分原始token 子串匹配无 rapidfuzz 语义近似，召回质量低
无遗忘/去重/上限memory 表无限增长长期使用后 prompt 膨胀，性能下降
compact 摘要未存为情景记忆摘要只用于 prompt，不落 DB无法跨会话检索历史摘要

一句话总结：循环的每一处失败都被设计成「降级继续」而不是「崩溃终止」—— 工具异常变结果文本、压缩失败变原样、摘要失败变剪枝、权限超时变拒绝、子代理异常变错误摘要。 真正会让 run 停下来的只有五件事：模型说完了、上下文彻底超窗、40 轮用尽、用户 abort、provider 抛错。
